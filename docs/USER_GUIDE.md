# LightOffice 使用指南 (User Guide)

LightOffice 是基于 ONLYOFFICE Desktop Editors 的内网轻量版办公套件，
支持 Word / Excel / PowerPoint 格式（.docx / .xlsx / .pptx）以及 PDF 的
创建、编辑与协同。

## 1. 安装

### Linux (Debian / Ubuntu)

```bash
sudo apt install ./WPS-Lite-linux-amd64.deb
WPS-Lite
```

### Windows

双击 `WPS-Lite-win-x64.exe`，按向导完成安装；桌面与开始菜单会出现
**LightOffice** 图标。

### macOS

macOS 有两个安装包，请按机型选择：

| 机型 | 安装包 |
|---|---|
| Apple 芯片（M1 及以后） | `WPS-Lite-macos-arm64.dmg` |
| Intel 芯片 | `WPS-Lite-macos-x86_64.dmg` |

不确定时，点击左上角苹果菜单 →「关于本机」，「芯片」一栏写着 Apple 即选
arm64，写着 Intel 即选 x86_64。装错架构不会损坏任何东西，应用只是无法启动。

打开对应的 .dmg，将 **LightOffice** 拖入「应用程序」。
首次启动如提示「无法验证开发者」，请在
**系统设置 → 隐私与安全性** 中点击「仍要打开」——本应用采用 ad-hoc 签名
（内网分发，未经 Apple 公证），这是预期提示，不代表安装包有问题。

## 2. 首次启动

**待补截图（`startup.png`）** — 应用完成启动后的起始页全窗口截图。
需包含：左侧最近文档列表、右侧四个新建入口、以及左上角的 LightOffice 品牌标识。
状态要求：干净的首次启动（无最近文档），窗口宽度 1280px。

启动画面结束后进入起始页，左侧为最近文档，右侧为新建入口：

- **文档** — 新建 .docx
- **表格** — 新建 .xlsx
- **演示文稿** — 新建 .pptx
- **PDF** — 新建或打开 PDF

## 3. 连接内网云盘

**待补截图（`connect-cloud.png`）** — 「连接到云端」对话框。
需包含：已预填的内网地址（应显示为 `https://` 开头的内网地址，不是空白输入框），
这是与标准版 ONLYOFFICE 最直观的差异。
状态要求：对话框刚打开、尚未点击连接时。

LightOffice 默认连接贵司内网 Nextcloud，无需手动输入地址。

1. 点击起始页左下角的 **连接到云端**。
2. 在提供方列表中选择 **LightOffice 内网云**（地址已预填为
   `http://10.0.7.10:8080`）。
3. 输入您的域账号与密码，点击 **连接**。
4. 连接成功后，云盘会作为一个新标签页出现，可直接双击文档打开编辑。

> 如果贵司使用了别的地址，请向 IT 管理员索取，并在地址栏中替换预填值。

## 4. 协同编辑

**待补截图（`coedit.png`）** — 两名用户同时编辑同一文档。
需包含：对方光标及其姓名标签、以及右上角的在线用户头像。
状态要求：两个客户端连接到同一文档，对方正在输入。

多人同时打开同一份云端文档时：

- 其他人的光标会以不同颜色显示，并标注其姓名。
- 编辑内容实时同步，无需手动刷新。
- 若某份文件正被他人以独占方式编辑，您会看到「文件已锁定」提示；
  此时可选择**只读打开**，待对方关闭后再编辑。

## 5. 与标准版 ONLYOFFICE 的差异

LightOffice 为内网轻量部署做了裁剪，以下功能**不包含**：

| 功能 | 状态 | 说明 |
|---|---|---|
| AI 助手 | 已移除 | 需访问外部 AI 服务，不适用于内网环境 |
| 插件市场 / 第三方插件 | 已移除 | 插件宿主已关闭 |
| 协作页签（审阅/修订工具栏） | 已隐藏 | 实时协同本身仍可用，仅隐藏高级审阅工具栏 |
| 公有云提供方（Dropbox / Box / kDrive 等） | 已移除 | 仅保留内网存储 |
| 拼写检查语言 | 仅英语 | 上游未提供中文 hunspell 词典 |

## 6. 界面主题

**待补截图（`theme.png`）** — 主题切换前后的对比图（左右并排）。
需包含：同一份文档在两种主题下的工具栏与文档区，以便看出配色差异。

## 7. 常见问题

**Q：连接云端时提示地址不受信任？**
A：该地址未加入 Nextcloud 的信任域名单，请联系 IT 管理员。

**Q：文档打开后一直显示加载中？**
A：通常是内网 Document Server 未就绪，请联系 IT 管理员检查服务状态。

**Q：拼写检查没有中文？**
A：ONLYOFFICE 上游未提供中文 hunspell 词典，中文拼写检查不可用，
这不是安装问题。

**Q：找不到「审阅」工具栏？**
A：该页签在本版本中已隐藏。批注与修订记录仍可通过右键菜单使用。
